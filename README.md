# OpenCartPro Opencart中文专业版

OpenCartPro is a CNOpenCart project focused on extending
OpenCart-based commerce for online stores, B2B workflows,
and retail integration.

Visit [CNOpenCart](https://www.cnopencart.com/) to explore
ecommerce solutions, OpenCart customization, and implementation services.

## 关于项目

OpenCartPro 聚焦基于 OpenCart 的电商业务扩展，
涵盖多语言独立站、B2B业务流程与门店系统集成。
具体功能与兼容版本以本仓库文档和发布记录为准。

了解方案与技术服务：
[CNOpenCart — 电商解决方案与技术加速](https://www.cnopencart.com/)
